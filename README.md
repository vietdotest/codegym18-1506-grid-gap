# Grid Gap

Đủ hai ví dụ: grid-gap 20px và 30px 10px; vẫn sử dụng thuộc tính grid-gap theo đề.

## Chạy
Mở index.html trong trình duyệt. Các ví dụ có kích thước cố định được đặt trong khung cuộn ở màn hình nhỏ để giữ đúng giá trị thuộc tính.

## Kiểm tra
Đã mở 375, 768, 1440 px và kiểm tra computed grid columns/rows/gap, vị trí ô đầu; ảnh result.png chụp các ví dụ khi chạy.
